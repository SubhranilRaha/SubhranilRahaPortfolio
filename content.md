## About (CMS: siteSettings.about, rich text)

I'm a software engineer on the platform engineering team at EY GDS, where I build agentic AI and cloud solutions: Python backends that turn infrastructure descriptions into architecture diagrams, and delivery automation with Azure, GitHub Actions and Terraform.

I started building in 2022, well before my first full-time role. I taught Solidity as a blockchain instructor, contributed to Hyperledger Fabric as a Linux Foundation mentee, led freelance teams that shipped an app to Google Play, and built DApps on Stellar. That mix taught me to read unfamiliar code quickly, test what I ship, and explain technical decisions clearly, whether to a client or to a room of 200 people.

Today I'm going deep on cloud and DevOps. I hold the GitHub Copilot (GH-300) and Azure Fundamentals (AZ-900) certifications, I'm preparing for Azure Administrator (AZ-104), and I write up what I learn after every session of my AWS Cloud & DevOps program.
